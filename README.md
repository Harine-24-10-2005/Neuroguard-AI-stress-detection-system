AI Multi Model Smart Stress Monitoring System                                                                                                                                                  
Descriptive:
NeuroGuard is a production-ready, full-stack AI web application that detects stress levels using a multi-modal approach combining Questionnaire Analysis, Face Recognition, and Voice Analysis.
The system collects psychological responses, facial expressions, and vocal features, then processes them through a real-time Django backend. 
Using an intelligent AI fusion model with weighted scoring (25% Questionnaire, 35% Voice, 40% Face), NeuroGuard generates a unified and accurate stress score. 
With interactive dashboard visualizations and scalable architecture, it provides a reliable solution for corporate wellness, healthcare screening, and mental health monitoring.
